出发前的小问题

现在可以在网页里玩吗？

这次提供 Windows 下载版；这个网页是游戏介绍页。解压下载包后即可在本机试玩。

这是正式版吗？

这是 V56 开发试玩。首局体验、画面与平衡仍在调整；部分小窗口文字偏小，一些装备共用卡图。它还会继续成长。

想反馈问题，去哪里？

在 GitHub Issues 留言。最想听你说：哪次推移很有趣、哪里没看懂、第一次犹豫发生在哪一步。欢迎附上截图和版本号。
